# Data Retention Draft - Legal Review Required

HamdhyTech and each institute must agree documented retention periods before production. Keep active account, student, class, attendance, audit, notification, SMS delivery, and consent data only as long as operationally and legally required. Prefer archival with restricted access over deletion when an institute has a valid record-keeping duty.

Delete expired device tokens promptly. Minimize provider response content and avoid sensitive message bodies in logs. Define verified deletion, backup expiry, legal holds, institute offboarding, and audit retention before launch. Student photographs are not collected. Contact `dev.hamdhytech@gmail.com`.
